# VALKRON — Architectural Appliances

A faithful interactive recreation of the supplied Valkron Appliances recording, built as a dependency-free responsive website.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Dark luxury architectural-appliance interface
- Responsive desktop/tablet/mobile layout
- Search and category filtering
- Sorting by price/rating
- Product cards with specifications
- Product specification modal
- Wishlist interaction
- Cart drawer with live totals
- Contact/technical consultation form
- AI Concierge panel with local demo responses
- Hero spotlight product
- Consultation and footer sections
- Local image assets extracted from the supplied reference recording

## Note
The checkout is implemented as a working front-end demo. Live payments require a real payment provider and backend credentials, which should never be hard-coded into a static project.
